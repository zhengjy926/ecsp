## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in this repo, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, default label strings unchanged. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Protocol spec

`docs/specs/ecsp-spec.md` is the authoritative ECSP serial protocol spec, and an input to this project rather than a decision about it. Read it before changing frame layout, command codes, response codes, or timing.
