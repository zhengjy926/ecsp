# 事务序号缓存的生命周期是“主机的一次运行”

从机的事务序号缓存于两处清空：从机软复位，以及**从机收到握手请求（0x01）时**。后者是规范现有条款的缺口——§4.2 只写了“从机发生软复位后清空该缓存”。

事务序号的作用域是主机的一次运行，而不是从机的一次运行：主机重启后，它为每台从机维护的单调计数器从 0 重新开始，而从机缓存里可能仍留着 (命令码, seq=0) 的旧条目。主机重启后的第一次动作就会命中该条目，被回放一个它无法理解的历史应答，且真正的动作永远不执行。

## Consequences

规范需补一句清空条件，随从机引擎（M1）的修订批次落地。

链路故障恢复后**不自动重发业务请求**：恢复流程必然经过一次握手，而握手已清空缓存；此时重发一个非幂等动作就是一次全新的执行。是否再做由应用在事务回调里决定。
